운화당 - LLM 기반 맞춤 리포트 서비스

OpenAI·Claude API로 60쪽 안팎의 맞춤 PDF 리포트를 생성하는 서비스를 구축하고, 기획부터 실제 고객 발송까지 전 과정을 직접 수행했습니다.

핵심 구현

  • JSON 스키마 기반 구조화 응답과 규칙 기반 검사를 적용하고, 검증 실패 사유를 다음 생성 요청에 전달하는 자기 교정 루프를 구현했습니다. 오류 유형별로 재시도·경고 정책을 분리해 불필요한 API 호출을 줄였습니다.
  • HTML/CSS 템플릿으로 리포트를 조판하고, 이미지 최적화로 PDF 용량을 78MB에서 4.7MB로 줄였습니다. 같은 디자인을 적용한 HTML 메일과 Next.js 소개 페이지도 구현했습니다.

검증·운영

  • 생성 결과를 사람이 검토한 뒤 문제가 있는 장만 선택해 재생성하도록 구성했습니다. 전체 생성에 10~20분이 걸리는 작업의 진행 상황을 실시간으로 표시했습니다.
  • Claude Code를 활용해 개발하며 참고 PDF 분석과 명세 작성, 시안 비교, 생성 결과 검토·테스트를 수행했고, 1주일 만에 기획부터 실제 고객 발송까지 진행했습니다.
